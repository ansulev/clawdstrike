```typescript
interface GenericGuardPlaygroundProps {
  guard: GuardName;
  actionType: 'file_access' | 'file_write' | 'network_egress' | 'shell_command' | 'mcp_tool' | 'patch' | 'text' | 'custom';
  placeholder: string;
  defaultInput?: string;
  config?: Record<string, unknown>;
  examples?: { label: string; value: string }[];
  customActionType?: string; // For CUA guards (e.g., 'remote.clipboard')
}
```

Implementation:
- Use a textarea for input (not CodeMirror -- keep it lightweight unlike the prompt injection playground)
- Show example pill buttons at top (like prompt-injection-playground.tsx does with EXAMPLE_PAYLOADS)
- Build the GuardAction from actionType + input using the same `buildAction` pattern from bypass-challenge.tsx (but handle custom with customActionType prop)
- Call `evaluateGuard(guard, config ?? {}, action)` on submit
- Display verdict using `VerdictDisplay` component after converting via `guardResultToVerdict()`
- Show loading state on the button during evaluation
- Layout: single column (no split pane needed -- input on top, verdict below), wrapped in a Card with border
