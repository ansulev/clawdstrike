       - ForbiddenPathConfig: `enabled` (boolean), `patterns` (string[]), `exceptions` (string[]), `additional_patterns` (string[]), `remove_patterns` (string[])
       - PathAllowlistConfig: `enabled` (boolean), `allowed_paths` (string[])
       - EgressAllowlistConfig: `enabled` (boolean), `allow` (string[]), `block` (string[]), `default_action` (enum: allow/block)
       - SecretLeakConfig: `enabled` (boolean), `patterns` (array of {name, pattern, severity}), `skip_paths` (string[])
       - ShellCommandConfig: `enabled` (boolean), `blocked_commands` (string[]), `blocked_patterns` (string[]), `allowed_commands` (string[])
       - McpToolConfig: `enabled` (boolean), `allow` (string[]), `block` (string[]), `require_confirmation` (string[]), `default_action` (enum: allow/block), `max_args_size` (integer)
       - PatchIntegrityConfig: `enabled` (boolean), `max_additions` (integer), `max_deletions` (integer), `require_balance` (boolean), `max_imbalance_ratio` (number), `forbidden_patterns` (string[])
       - PromptInjectionConfig: `enabled` (boolean), `threshold` (number 0-1), `max_scan_bytes` (integer)
       - JailbreakConfig: `enabled` (boolean), `threshold` (number 0-1), `layers` (object)

       - InputInjectionCapabilityConfig: `enabled` (boolean), `allowed_capabilities` (string[]), `blocked_capabilities` (string[])
       - SpiderSenseConfig: `enabled` (boolean), `threshold` (number), `pattern_db_path` (string)
       - PolicySettings: `fail_fast` (boolean), `verbose_logging` (boolean), `session_timeout_secs` (integer)
       - Export as `export const policySchema = { ... } as const;`

    3. Create `apps/academy/src/lib/policy-linter.ts`:
       - Import `linter, Diagnostic` from `@codemirror/lint`
       - Import `Ajv` from `ajv`, `YAML` from `yaml`, and `policySchema` from `./policy-schema`
       - Create module-level `const ajv = new Ajv({ allErrors: true, verbose: true })` and `const validate = ajv.compile(policySchema)`
       - Export `policyLinter = linter((view) => { ... }, { delay: 300 })`:
         a. Parse YAML text with `YAML.parseDocument(text)` — if parse errors, map each to a Diagnostic using `error.pos[0]` for character offset
         b. If parse succeeds, call `validate(doc.toJSON())`
         c. For each Ajv error, call `findYamlPosition(text, error.instancePath)` to get `{from, to}`, then `formatAjvError(error)` for the message
         d. Return array of Diagnostic objects with severity 'error'
       - Export `findYamlPosition(yamlText: string, jsonPath: string): { from: number; to: number }`:
         a. Parse with `YAML.parseDocument(yamlText)`
         b. Walk segments of jsonPath through YAML Map/Seq nodes using `isMap`/`isSeq`/`isScalar` type guards
         c. If node found with `range` property, return `{ from: range[0], to: range[1] }`
         d. Fallback: `{ from: 0, to: yamlText.indexOf('\n') || yamlText.length }`
       - Export `formatAjvError(error): string`:
         a. For `additionalProperties` keyword: `Unknown field "${params.additionalProperty}" in ${field}`
         b. For `enum` keyword: `${field}: must be one of ${params.allowedValues.join(', ')}`
         c. Default: `${field}: ${error.message}`
