    1. Create `apps/academy/src/hooks/use-keyboard-nav.ts` (client-side hook):
       - `'use client'` not needed in hooks file (only components) — but export is used by client component
       - Import `useEffect` from `react`, `useRouter`, `usePathname` from `next/navigation`
       - Export `function useKeyboardNav()`:
         a. Get `pathname` from `usePathname()`, `router` from `useRouter()`
         b. Parse pathname to extract track slug and lesson slug: `/tracks/${trackSlug}/${lessonSlug}`
         c. useEffect with keydown listener:
            - **Focus guard:** Check `document.activeElement`. If active element is inside `.cm-editor`, or is a `textarea`, `input`, or `[contenteditable]`, return without handling. This prevents arrow keys from being intercepted when the user is typing in CodeMirror or form fields.
            - `ArrowLeft` -> navigate to previous lesson (use `getLessonNavigation` from content.ts). IMPORTANT: `getLessonNavigation` is a server-side function (uses `fs`). Instead, the hook should receive prev/next paths as props OR compute from pathname. Since content.ts uses fs, create a client-safe version: pass `prevPath`/`nextPath` as props to the hook from the server layout, or use a different approach:
              - Option A: The layout (server component) passes prev/next to a client wrapper
              - Option B: The hook reads from DOM (data attributes on LessonNav component)
              - Best approach: Create a `KeyboardNavProvider` client component that receives prev/next from the server layout and registers the listener. BUT since the tracks layout is a server component rendering `{children}`, and children could be any lesson, we cannot know prev/next at layout level without parsing the URL.
              - ACTUAL BEST APPROACH: Use a client component wrapper that receives `tracks` data (already passed to Sidebar), walks the flat lesson list to find current lesson by pathname, and derives prev/next. This avoids any fs calls on the client.
            - `ArrowRight` -> navigate to next lesson
         d. Dependencies: `[pathname, router]` (and the tracks data if passed as prop)

    2. Create a client wrapper component `KeyboardNavWrapper` within layout or as a separate file:
       - Since the search command and keyboard nav both need to be client components and the layout is a server component, create `apps/academy/src/components/layout/client-shell.tsx`:
         ```typescript
         'use client';
         import { SearchCommand } from '@/components/search/search-command';
         import { useKeyboardNav } from '@/hooks/use-keyboard-nav';
         import type { TrackMeta } from '@/lib/content';

         export function ClientShell({ tracks }: { tracks: TrackMeta[] }) {
           useKeyboardNav(tracks);
           return <SearchCommand />;
         }
         ```
       - The hook receives the full tracks array (serializable, already passed to Sidebar in layout.tsx)
       - Inside the hook: flatten all lessons from all tracks, find the current lesson by pathname, derive prev/next
