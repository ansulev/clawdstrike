       - Export `function buildInheritanceTree(...)`:
         a. Take `index: Record<string, { name: string; extends?: string; description: string }>` and `data: Record<string, any>` parameters
         b. Find roots: entries where `extends` is undefined/null
         c. For each root, recursively build children:
            - Find entries whose `extends` matches the parent id, OR `extends` is `clawdstrike:${parentId}` (strip prefix for matching)
            - For each child, compute `overrides`: keys in child's `guards` object that also exist in parent's `guards` object
         d. Return array of TreeNode roots

       - Export `function InheritanceTree()`:
         a. Call `buildInheritanceTree(rulesetIndex, rulesets)` to get tree data

            - When expanded: show overrides list as small tags/badges, then render children recursively
            - Indent children with `ml-6` and use `border-l-2 border-muted` for the connecting line
