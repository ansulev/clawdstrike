# Prompt Injection Guard

The Prompt Injection Guard detects attempts to override an AI agent's instructions
through crafted text inputs.

## How It Works

The guard analyzes input text for patterns commonly used in prompt injection attacks:

```python
# Common prompt injection patterns:
"Ignore all previous instructions and..."
"You are now DAN (Do Anything Now)..."
"SYSTEM OVERRIDE: new instructions follow"
```
